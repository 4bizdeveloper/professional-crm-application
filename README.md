# Professional CRM Application

MERN + TypeScript CRM monorepo with React SPA, Express REST API, Apollo GraphQL API, MongoDB/Mongoose, JWT authentication, responsive UI, and decoupled service architecture.

Core modules: dashboard, companies, contacts, leads, deals/pipeline, tasks, activities, products, users/roles, search and pagination.

Setup: cp apps/api/.env.example apps/api/.env; set MONGODB_URI and JWT_SECRET; npm install; npm run seed; npm run dev.
